---
title: Upgrading
description: Move to a new version.
icon: arrow-up-circle
---

<Steps>
  <Step title="Back up">
    The database and the secret key. See [Backups](/self-hosting/backups).
  </Step>
  <Step title="Pull and restart">
    ```sh
    docker compose pull
    docker compose up -d
    ```
    Pin a version with a tag such as `ghcr.io/armistice-group/ac-modern:0.1` instead of `latest`. Building from source: `git pull && docker compose up -d --build`.
  </Step>
  <Step title="Check">
    Migrations run on startup. The version shows at the bottom of the sidebar and in `/api/health`.
  </Step>
</Steps>

<Note>
  Migrations only add things. Rolling back to an older version after a migration isn't supported: restore the backup instead.
</Note>
